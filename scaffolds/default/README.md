## Overview

This laboratory was created from the CyberLab default scaffold.

## Getting started

1. Update `lab.yaml` with the learning objective and metadata.
2. Add one or more services to `compose.yaml`.
3. Place application files in `application/`, helper scripts in `scripts/`,
   and seed data in `seed/`.
4. Validate and run the lab:

   ```bash
   cyberlab lab validate {{LAB_ID}}
   cyberlab lab run {{LAB_ID}}
   ```
