# {{LAB_NAME}}

Kali Linux workspace generated by CyberLab for authorized, isolated security
assessment exercises. This template uses the `{{KALI_PROFILE}}` profile.

## Start and open the console

```bash
uv run cyberlab lab run {{LAB_ID}}
uv run cyberlab lab exec {{LAB_ID}}
```

The container runs as the unprivileged `cyberlab` user. Leave the console with
`exit`. Run a single command without opening a shell with:

```bash
uv run cyberlab lab exec {{LAB_ID}} -c "nmap --version"
```

## Profiles

The image profile is selected when the lab is created:

```bash
uv run cyberlab lab create {{LAB_ID}} --template kali --profile web
```

| Profile | Included tools |
| --- | --- |
| `minimal` | Connectivity and DNS diagnostics |
| `web` | `nmap`, `nikto`, `whatweb`, `dirb`, `sqlmap` and web utilities |
| `network` | `nmap`, `tcpdump`, `traceroute` and network diagnostics |

## Connect to an authorized target lab

Compose projects have separate networks by default. After starting an
authorized target, connect this container to the target's Docker network:

```bash
docker network connect --alias rainloop rainloop-pentest_lab-network cyberlab-{{LAB_ID}}
```

From the Kali console, the target can then be reached at `http://rainloop`.
Disconnect it after the exercise:

```bash
docker network disconnect rainloop-pentest_lab-network cyberlab-{{LAB_ID}}
```

Only connect to laboratories you own or are explicitly authorized to assess.
